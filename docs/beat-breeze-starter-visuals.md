# Beat Breeze starter visual previews

These are optimized marketing previews of the genuine **Starter visuals — included**
pack used by Beat Breeze TV Channels. They are silent, ten-second, 16:9 loops and
load only inside the active visual preview on the Beat Breeze product page.

| Public preview | Product source |
| --- | --- |
| `warm-coffee-crema` | `backend/scripts/starter_visuals_work/warm-coffee-crema` |
| `fresh-palm-shadows` | `backend/scripts/starter_visuals_work/fresh-palm-shadows` |
| `neon-wet-street` | `backend/scripts/starter_visuals_work/neon-wet-street` |

The product-source files live in the ACE Music Player repository. The public MP4
copies are resized to 1280×720, stripped of audio and compressed for web delivery.
The JPEG files are the curated product poster frames.
